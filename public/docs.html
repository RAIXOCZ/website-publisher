Jak zveřejnit statický web během pár sekund.

Jak zveřejnit web

  1. Na hlavní stránce přetáhněte složku s webem do vyznačeného pole, případně klikněte na Přidat složku. První složka tvoří kořen webu.
  2. Ve stromu souborů můžete web upravit: přidat další soubory nebo složky, vytvořit novou složku, soubory a složky přesouvat přetažením, přejmenovat (dvojklikem) nebo odebrat. Další možnosti, třeba nahrazení souboru nebo celé složky, najdete pod tlačítkem ⋯ u každé položky.
  3. Název webu se doplní podle názvu první složky (bez složky se vygeneruje náhodný kód). Chcete-li jiný, napište ho do adresního řádku nad polem pro nahrání.
  4. Tlačítkem Náhled si web můžete nejdřív prohlédnout na dočasné adrese preview-…. Náhled po 5 minutách vyprší.
  5. Vyplňte e-mail, jméno a příjmení a klikněte na Poslat potvrzení. Na e-mail vám přijde odkaz; po jeho otevření a potvrzení je web online a zároveň vznikne váš účet. Odkaz platí 24 hodin.

Pokud už účet máte a jste přihlášení, web se zveřejní hned bez potvrzování.

Co má složka obsahovat

  • Úvodní stránku index.html přímo ve složce.
  • Cokoli dalšího: CSS, JavaScript, obrázky, fonty, podsložky. Struktura zůstane zachovaná.
  • Fungují jen statické soubory. PHP, Node.js a databáze se nespouští.
  • Nedávejte na web osobní údaje, které nemusí být veřejné (svoje ani cizí). Web je veřejný a za jeho obsah odpovídáte vy, viz podmínky použití.
muj-web/
  ├── index.html
  ├── o-nas.html
  ├── css/style.css
  └── img/logo.png

Pokud nahrajete složku, která obsahuje jen jednu další složku (třeba muj-web/dist/…), zveřejní se automaticky její obsah.

Nahrání .zip souboru

Místo složky můžete nahrát jeden soubor .zip. Po nahrání se rozbalí a zveřejní stejně jako složka. Hodí se pro velké weby nebo prohlížeče, které neumí nahrávat složky.

Účet a přihlášení

  • Účet nemá heslo. Přihlásíte se na stránce Účet odkazem, který vám pošleme e-mailem.
  • V účtu najdete své weby, osobní údaje, API tokeny a historii aktivit.

Úprava webu

V sekci Moje weby klikněte u webu na Upravit. Jeho soubory se otevřou ve stromu: můžete nahradit jednotlivé soubory, nahradit obsah složky nebo celý web jinou složkou, přidat soubory a složky, přesouvat a mazat. Změny si můžete prohlédnout v náhledu a pak klikněte na Uložit změny. Výměna proběhne najednou, návštěvníci nikdy neuvidí napůl nahraný web.

Smazání webu a účtu

Web smažete tlačítkem Smazat u webu, účet na stránce Účet (smazání potvrdíte odkazem v e-mailu). Smazané weby okamžitě přestanou být veřejné. Data ještě 90 dní uchováváme kvůli řešení případného zneužití a poté je trvale smažeme; pokud chcete smazání hned, napište na martin@freepages.dev.

Příkazová řádka (curl)

Na stránce Účet si vytvořte API token. S ním můžete zveřejňovat a aktualizovat weby například ze skriptu nebo CI:

# zveřejnění nebo aktualizace webu ze .zip souboru
curl -H "Authorization: Bearer $FREEPAGES_TOKEN" \
     -F name=muj-web -F overwrite=1 -F f=@web.zip \
     …
  • name – název webu. Bez overwrite=1 dostane web při obsazeném názvu příponu, s ním nahradí váš existující web.
  • f – soubory. Jeden .zip se rozbalí; více souborů pošlete jako dvojice -F p=cesta/soubor.html -F f=@soubor.html (cesta p vždy před souborem).
  • preview=1 – místo zveřejnění vytvoří 5minutový náhled; adresa je v odpovědi.
  • Odpověď je JSON s adresou webu (url). Chyby vrací {"error": "…"} s HTTP kódem 4xx.

Weby s heslem

Z IP adres, které povolí správce, lze zveřejňovat bez účtu. Takový web dostane heslo (například k7mq-2xpa-9fve), které se uloží do prohlížeče; bez něj web nejde nahradit ani smazat. Na jiném zařízení ho přidáte tlačítkem Přidat web s heslem.

Hezké adresy a chybová stránka

  • Adresa /o-nas zobrazí soubor o-nas.html, příponu psát nemusíte.
  • Když přidáte soubor 404.html, zobrazí se u neexistujících stránek.
  • Složka bez index.html zobrazí seznam svých souborů.

Pravidla pro název

  • Malá písmena bez diakritiky, číslice a pomlčky, nejvýše 63 znaků.
  • Velká písmena, mezery a háčky se převedou automaticky (Můj Web → muj-web).
  • Pokud je název už obsazený, přidá se k němu pomlčka a tři náhodné znaky, například muj-web-k3x.
  • Některé názvy jsou rezervované, například admin, api, docs nebo www, a názvy začínající preview-.

Guide

How to publish a static website in a few seconds.

How to publish a site

  1. On the home page, drag your site's folder into the marked area, or click Add folder. The first folder becomes the root of the site.
  2. In the file tree you can adjust the site: add more files or folders, create a new folder, move files and folders by dragging, rename them (double-click) or remove them. More options, such as replacing a file or a whole folder, are under the ⋯ button of each item.
  3. The site name is filled in from the first folder's name (without a folder, a random code is generated). If you want a different one, type it into the address bar above the upload area.
  4. Click Preview to look at the site first at a temporary preview-… address. The preview expires after 5 minutes.
  5. Enter your e-mail, first and last name and click Send confirmation. You will get a link by e-mail; once you open and confirm it, the site is online and your account is created. The link is valid for 24 hours.

If you already have an account and are signed in, the site is published right away without confirmation.

The site will be available at …

What the folder should contain

  • A start page index.html directly in the folder.
  • Anything else: CSS, JavaScript, images, fonts, subfolders. The structure is kept as it is.
  • Only static files work. PHP, Node.js and databases are not run.
  • Avoid putting personal data on your site unless it needs to be public, whether your own or anyone else's. The site is public and you are responsible for its content, see the terms of use.
my-site/
├── index.html
├── about.html
├── css/style.css
└── img/logo.png

If you upload a folder that only contains one other folder (for example my-site/dist/…), its contents are published automatically.

Uploading a .zip file

Instead of a folder you can upload a single .zip file. It is extracted and published just like a folder. Handy for large sites or browsers that cannot upload folders.

Account and signing in

  • Accounts have no password. Sign in on the Account page with a link we send you by e-mail.
  • Your account shows your sites, personal details, API tokens and activity history.

Editing a site

Under My sites, click Edit. The site's files open in the tree: you can replace single files, replace a folder's contents or the whole site with another folder, add files and folders, move and remove them. Check the changes in a preview, then click Save changes. The switch happens at once, so visitors never see a half-uploaded site.

Deleting a site or account

Delete a site with its Delete button, and your account on the Account page (you confirm with a link sent by e-mail). Deleted sites stop being public immediately. We keep the data for 90 more days to deal with possible abuse and then delete it permanently; to have it deleted right away, write to martin@freepages.dev.

Command line (curl)

Create an API token on the Account page. With it you can publish and update sites, e.g. from a script or CI:

# publish or update a site from a .zip file
curl -H "Authorization: Bearer $FREEPAGES_TOKEN" \
     -F name=my-site -F overwrite=1 -F f=@site.zip \
     …
  • name – the site name. Without overwrite=1 a taken name gets a suffix; with it, your existing site is replaced.
  • f – files. A single .zip is extracted; send several files as pairs -F p=path/file.html -F f=@file.html (the path p always before the file).
  • preview=1 – creates a 5-minute preview instead of publishing; its address is in the response.
  • The response is JSON with the site's address (url). Errors return {"error": "…"} with a 4xx HTTP status.

Password sites

From IP addresses allowed by the administrator, sites can be published without an account. Such a site gets a password (for example k7mq-2xpa-9fve), saved in your browser; without it the site cannot be replaced or deleted. On another device, add it with Add a password site.

Clean URLs and error page

  • The address /about serves about.html; you don't have to type the extension.
  • Add a 404.html file and it is shown for pages that don't exist.
  • A folder without index.html shows a list of its files.

Name rules

  • Lowercase letters without accents, numbers and dashes, at most 63 characters.
  • Capitals, spaces and accents are converted automatically (My Site → my-site).
  • If the name is already taken, a dash and three random characters are added, for example my-site-k3x.
  • Some names are reserved, for example admin, api, docs or www, and names starting with preview-.
