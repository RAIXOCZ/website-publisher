Jak zveřejnit statický web během pár sekund.

Jak zveřejnit web

  1. Na hlavní stránce přetáhněte složku s webem do vyznačeného pole, případně klikněte na Vybrat složku.
  2. Název webu se doplní podle názvu složky. Chcete-li jiný, napište ho do adresního řádku nad polem pro nahrání.
  3. Po dokončení nahrávání je web okamžitě online. Odkaz si můžete zkopírovat nebo rovnou otevřít.
  4. Zobrazí se heslo k webu. Uschovejte si ho, budete ho potřebovat pro aktualizaci nebo smazání.

Nepotřebujete žádný účet ani přihlášení.

Web bude dostupný na adrese …

Co má složka obsahovat

  • Úvodní stránku index.html přímo ve složce.
  • Cokoli dalšího: CSS, JavaScript, obrázky, fonty, podsložky. Struktura zůstane zachovaná.
  • Fungují jen statické soubory. PHP, Node.js a databáze se nespouští.
  • Nevkládejte na web osobní údaje (svoje ani cizí). Web je veřejný a za jeho obsah odpovídáte vy, viz podmínky použití.
muj-web/
  ├── index.html
  ├── o-nas.html
  ├── css/style.css
  └── img/logo.png

Pokud nahrajete složku, která obsahuje jen jednu další složku (třeba muj-web/dist/…), zveřejní se automaticky její obsah.

Nahrání .zip souboru

Místo složky můžete nahrát jeden soubor .zip. Po nahrání se rozbalí a zveřejní stejně jako složka. Hodí se pro velké weby nebo prohlížeče, které neumí nahrávat složky.

Heslo k webu

  • Každý web dostane při prvním zveřejnění vlastní heslo, například k7mq-2xpa-9fve.
  • Bez hesla nikdo nemůže web nahradit ani smazat.
  • Heslo se uloží do vašeho prohlížeče a web najdete v sekci Moje weby.
  • Na jiném zařízení (nebo po vymazání dat prohlížeče) web přidáte tlačítkem Přidat existující web, kam zadáte název a heslo.
  • Pokud heslo ztratíte, požádejte správce serveru o nové.

Aktualizace webu

V sekci Moje weby klikněte na Aktualizovat a vyberte složku s novou verzí. Nebo nahrajte složku se stejným názvem na hlavní stránce: aplikace se zeptá na heslo (pokud ho máte uložené, doplní ho sama). Výměna proběhne najednou, návštěvníci nikdy neuvidí napůl nahraný web.

Smazání webu

V sekci Moje weby klikněte na Smazat. Adresa webu tím přestane fungovat.

Hezké adresy a chybová stránka

  • Adresa /o-nas zobrazí soubor o-nas.html, příponu psát nemusíte.
  • Když přidáte soubor 404.html, zobrazí se u neexistujících stránek.
  • Složka bez index.html zobrazí seznam svých souborů.

Pravidla pro název

  • Malá písmena bez diakritiky, číslice a pomlčky, nejvýše 63 znaků.
  • Velká písmena, mezery a háčky se převedou automaticky (Můj Web → muj-web).
  • Některé názvy jsou rezervované, například admin, api, docs nebo www.

Guide

How to publish a static website in a few seconds.

How to publish a site

  1. On the home page, drop your website folder onto the marked area, or click Choose folder.
  2. The site name is taken from the folder name. To use a different one, type it into the address bar above the upload area.
  3. As soon as the upload finishes, the site is live. Copy the link or open it right away.
  4. You will see the site password. Keep it safe; you need it to update or delete the site.

No account or login is needed.

Your site will be available at …

What the folder should contain

  • A start page index.html directly in the folder.
  • Anything else: CSS, JavaScript, images, fonts, subfolders. The structure is kept as it is.
  • Only static files work. PHP, Node.js and databases are not run.
  • Do not put personal data (your own or anyone else's) on your site. The site is public and you are responsible for its content, see the terms of use.
my-site/
├── index.html
├── about.html
├── css/style.css
└── img/logo.png

If you upload a folder that only contains one other folder (for example my-site/dist/…), its contents are published automatically.

Uploading a .zip file

Instead of a folder you can upload a single .zip file. It is extracted and published just like a folder. Handy for large sites or browsers that cannot upload folders.

Site password

  • Every site gets its own password when it is first published, for example k7mq-2xpa-9fve.
  • Without the password nobody can replace or delete the site.
  • The password is saved in your browser and the site appears under My sites.
  • On another device (or after clearing browser data), add the site with Add existing site by entering its name and password.
  • If you lose the password, ask the server administrator for a new one.

Updating a site

Under My sites, click Update and choose the folder with the new version. Or upload a folder with the same name on the home page: the app asks for the password (and fills it in if it is saved). The switch happens at once, so visitors never see a half-uploaded site.

Deleting a site

Under My sites, click Delete. The site's address stops working.

Clean URLs and error page

  • The address /about serves about.html; you don't have to type the extension.
  • Add a 404.html file and it is shown for pages that don't exist.
  • A folder without index.html shows a list of its files.

Name rules

  • Lowercase letters without accents, numbers and dashes, at most 63 characters.
  • Capitals, spaces and accents are converted automatically (My Site → my-site).
  • Some names are reserved, for example admin, api, docs or www.

Limits

  • Maximum size of one upload: …
  • System files such as .DS_Store, Thumbs.db or __MACOSX are skipped.
