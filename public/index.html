    MCP server

    Zveřejněte web z AI asistenta

    freepages.dev má vestavěný MCP server (Model Context Protocol). Připojte ho k Claude, Cursoru, VS Code nebo jinému MCP klientovi a napište třeba „Zveřejni tuhle stránku na freepages.dev“. Asistent soubory nahraje a vrátí vám odkaz na hotový web.

    1. V aplikaci přidejte MCP server s adresou https://freepages.dev/mcp.
    2. Aplikace otevře okno pro přihlášení: zadáte e-mail a přístup potvrdíte odkazem. Účet vznikne automaticky.
    3. Požádejte asistenta, ať web zveřejní, aktualizuje, přejmenuje nebo smaže.
    # Claude Code
claude mcp add --transport http freepages.dev https://freepages.dev/mcp
    # Cursor, VS Code a další (JSON konfigurace)
{ "mcpServers": { "freepages.dev": { "type": "http", "url": "https://freepages.dev/mcp" } } }

    Nástroje serveru: publish_site, create_preview, list_sites, list_files, read_file, rename_site, delete_site, get_visits a get_account. Aplikace bez přihlašování (OAuth) připojíte API klíčem, podrobnosti najdete v návodu.

    Časté otázky

    Je freepages.dev opravdu zdarma?

    Ano. Zveřejnění i provoz webu jsou zdarma, platí jen limity úložiště: 50 MB na web a 100 MB na účet.

    Jaké weby můžu zveřejnit?

    Statické weby: HTML, CSS, JavaScript, obrázky a fonty. Serverový kód (PHP, Node.js) ani databáze nejsou k dispozici. Aplikace z Reactu, Vue, Astra a dalších nejdřív sestavte a nahrajte složku s výstupem buildu.

    Potřebuji účet nebo heslo?

    Heslo ne. Při prvním zveřejnění zadáte e-mail a po potvrzení odkazu je web online a účet vytvořený. Příště se přihlásíte zase odkazem z e-mailu.

    Může web zveřejnit AI asistent?

    Ano. Přes MCP server na adrese https://freepages.dev/mcp umí Claude, Cursor, VS Code a další asistenti weby zveřejnit, aktualizovat i smazat, vždy jen ve vašem účtu.

    Jak web aktualizuji nebo smažu?

    V přehledu Moje weby klikněte na Upravit, změňte soubory a zveřejněte znovu. Adresa zůstane stejná. Mazat a přejmenovávat můžete tamtéž, přes API nebo z AI asistenta.

    MCP server

    Publish a website from your AI assistant

    freepages.dev has a built-in MCP server (Model Context Protocol). Connect it to Claude, Cursor, VS Code or any other MCP client and say something like “Publish this page on freepages.dev”. The assistant uploads the files and hands you the link to the live site.

    1. Add an MCP server with the address https://freepages.dev/mcp in your app.
    2. The app opens a sign-in window: enter your e-mail and confirm access with the link. Your account is created automatically.
    3. Ask the assistant to publish, update, rename or delete a site.
    # Claude Code
claude mcp add --transport http freepages.dev https://freepages.dev/mcp
    # Cursor, VS Code and others (JSON config)
{ "mcpServers": { "freepages.dev": { "type": "http", "url": "https://freepages.dev/mcp" } } }

    Server tools: publish_site, create_preview, list_sites, list_files, read_file, rename_site, delete_site, get_visits and get_account. Apps without sign-in (OAuth) connect with an API key; see the guide for details.

    Frequently asked questions

    Is freepages.dev really free?

    Yes. Publishing and hosting are free; only storage limits apply: 50 MB per site and 100 MB per account.

    What kind of websites can I publish?

    Static websites: HTML, CSS, JavaScript, images and fonts. There is no server-side code (PHP, Node.js) or database. Build apps made with React, Vue, Astro and others first, then upload the build output folder.

    Do I need an account or a password?

    No password. The first time you publish, you enter your e-mail; once you confirm the link, the site is live and your account exists. Next time you sign in with an e-mail link again.

    Can an AI assistant publish my website?

    Yes. Through the MCP server at https://freepages.dev/mcp, Claude, Cursor, VS Code and other assistants can publish, update and delete sites, always only in your account.

    How do I update or delete a site?

    Under My sites, click Edit, change the files and publish again. The address stays the same. You can delete and rename sites there too, through the API or from your AI assistant.
